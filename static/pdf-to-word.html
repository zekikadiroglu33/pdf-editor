What it does

PDF to Word extracts the text from your PDF and rebuilds it as an editable Microsoft Word (.docx) file, right in your browser — no software to install.

How it works

  1. Your PDF is normalized server-side, then each page's text is decoded and its actual on-page position tracked, so lines can be told apart from paragraphs.
  2. Consecutive lines are grouped into paragraphs using the same heuristic tools like pdftotext -layout use: an ordinary line-wrap joins with a space, and a bigger gap (or a move back up the page) starts a new paragraph.
  3. The resulting paragraphs are written out as minimal OOXML WordprocessingML — one <w:p> per paragraph, with an explicit page break between pages — and streamed back as a .docx file.

FAQ

Will my tables, columns, or images be preserved?

No — this is best-effort text extraction, not layout reconstruction. Multi-column layouts and tables come out as a linear sequence of paragraphs, and images aren't carried over at all.

Does it work on scanned PDFs?

No — a scanned or image-only PDF has no underlying text to extract. You'd need to run OCR on it first.

Why is a sentence split into two paragraphs?

Paragraphs are inferred from vertical line spacing, so unusual line spacing in the source PDF can occasionally be misread as a paragraph break.

Can I convert to PowerPoint, Excel, or an image instead?

Yes — the full converter supports pptx, xlsx, HTML, plain text, SVG, PNG, JPEG, TIFF, and WEBP too.

Is my file stored anywhere?

No, files are processed in memory only and never written to persistent storage.
