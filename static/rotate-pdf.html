What it does

Rotate PDF fixes sideways or upside-down pages — rotate the whole document or just the pages you specify, 90° clockwise, 90° counterclockwise, or 180°.

How it works

  1. Choose a rotation angle and, optionally, which pages to rotate (e.g. 1,3,5-7) — leave pages blank to rotate the whole document.
  2. Your request is passed straight to qpdf --rotate=[+|-]angle:page-range, using an explicit relative rotation just like qpdf's own recommended usage.
  3. The rotated PDF is streamed back to your browser; page content itself is untouched, only each page's orientation flag changes.

Benefits

  • Free, no account or sign-up
  • Rotate the whole document or specific pages
  • 90°, -90°, or 180° in one request
  • Files never stored on the server

Examples

  • Fix a handful of pages that were scanned sideways in an otherwise correct document.
  • Rotate an entire document that was scanned upside-down.
  • Correct just the landscape pages in a mixed portrait/landscape report.

FAQ

Can I rotate just some pages, not the whole file?

Yes — enter a page list like 1,3,5-7; leave it blank to rotate every page.

What's the difference between 90° and -90°?

90° rotates clockwise, -90° rotates counterclockwise — pick whichever direction fixes your page's orientation.

Does rotating affect page content or quality?

No — only the page's orientation flag changes; the underlying content stream is untouched.

Can I rotate different pages by different amounts in one request?

Not in a single request — run rotate again with a different angle and page list for a second pass.

Is my file stored anywhere?

No, files are processed in memory only and never written to persistent storage.
