What it does

pdfer's editor finds and replaces text directly inside a PDF, in your browser, with no software to install. Drop in a file, either type the text to find or drag-select it right on the rendered page, type its replacement, and review every change — highlighted in yellow — before you download the edited file.

How it works

  1. Your PDF is normalized into a classic, uncompressed file, so its text becomes plain, searchable bytes.
  2. Your find/replace text is transcoded into the same single-byte encoding the PDF's font uses (Latin/WinAnsi by default, or Windows-1254 for Turkish), then matched and replaced byte-for-byte inside every text stream, with the replacement properly escaped for PDF syntax.
  3. The file is rebuilt with a fresh cross-reference table and recompressed, so the result opens cleanly in any PDF viewer.
  4. Nothing is written to disk on the server — the edited file is streamed straight back to your browser.

FAQ

Does this work on scanned PDFs?

No — a scanned or image-only PDF has no underlying text layer, so there's nothing to find or replace. You'd need to run OCR on it first.

Will replacing text change the page layout?

Replacement text keeps the original glyph positions, so a much longer replacement can overlap neighboring text. Short, similar-length replacements work best.

Is my file stored anywhere?

No. Your PDF is processed in memory for the duration of the request only and is never written to persistent storage.

Why didn't my search text match?

If a phrase is kerned into separate pieces by the original PDF (e.g. "AC" then "ME" as two operators), a search for "ACME" won't match — this depends on how the source document laid out its text, not on your search.

Can I undo a change?

Yes, up to the last 5 edits — but undo is held in your browser tab's memory only, so reload or closing the tab clears it. Download before you navigate away.
