What it does

Merge PDF combines two or more PDF files into a single document, right in your browser. Upload the files you want combined, in the order you want them to appear, and download one merged PDF.

How it works

  1. Select 2 or more PDF files — pdfer concatenates every page from every file server-side, in the order you added them.
  2. Nothing else touches your files: no re-encoding, no quality loss — pages are combined exactly as they were in the originals.
  3. The merged PDF is streamed straight back to your browser; nothing is written to disk on the server.

Benefits

  • Free, no account or sign-up
  • Merge as many files as you like in one request (each up to 50 MB)
  • Files never stored on the server
  • Original page order and quality preserved exactly

Examples

  • Combine scanned receipts into one PDF before submitting an expense report.
  • Merge a cover letter, resume, and portfolio into a single application PDF.
  • Stitch together multiple chapters or reports into one document for review.

FAQ

Is there a limit to how many files I can merge?

No hard limit on file count, but each individual file must be 50 MB or smaller.

What order will the pages be in?

Exactly the order you added the files, top to bottom.

Does merging reduce PDF quality?

No — the original pages are concatenated as-is; nothing is re-encoded or re-rendered.

Can I merge PDFs with different page sizes?

Yes — each page keeps its own original size; pdfer doesn't force pages to match.

Is my file stored anywhere?

No, files are processed in memory only and never written to persistent storage.
