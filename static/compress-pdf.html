What it does

Compress PDF shrinks a PDF's file size by re-encoding its internal streams and images, so it's easier to email or upload somewhere with a size limit.

How it works

  1. Your PDF is processed server-side to re-encode its internal streams, optionally with a JPEG quality setting for embedded images.
  2. Recognizable streams and images inside the file are re-encoded — fonts aren't touched and image resolution isn't downsampled, only what's already there gets re-compressed.
  3. Because of that, results vary a lot by input: a PDF full of large, uncompressed images can shrink dramatically, while a mostly-text or already-optimized PDF may barely shrink, and a tiny file can even grow slightly from the added overhead.

Benefits

  • Free, no account or sign-up
  • Optional JPEG quality control
  • Original page count and layout untouched
  • Files never stored on the server

Examples

  • Shrink a scanned contract full of high-resolution images before emailing it.
  • Get a large report under a portal's upload size limit before submitting it.
  • Reduce a PDF's size before archiving hundreds of them to save storage.

FAQ

Why didn't my file get much smaller?

Compress only re-encodes streams and images it already recognizes — a mostly-text PDF or one that's already optimized won't shrink much, since there's little left to compress.

Can I control the compression level?

Yes — set an optional JPEG quality (1-100) for embedded images; leave it blank to use the default.

Does compressing reduce image resolution?

No — this tool re-encodes images, it doesn't downsample their pixel dimensions. For that, use "Compress images" on the All Tools page.

Will my PDF lose quality?

Recompression can lower JPEG quality if you set it, but page content and text stay exactly as they were.

Is my file stored anywhere?

No, files are processed in memory only and never written to persistent storage.
