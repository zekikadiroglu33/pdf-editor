What it does

Split PDF breaks one PDF into multiple files — either by custom page ranges (like 1-3;4-6) or one file per page if you leave the ranges blank.

How it works

  1. Enter one or more ranges (like 1-3;4-6), or leave it blank to split every page into its own file.
  2. Each range is extracted as its own file server-side, one operation per output file, so page content, fonts, and formatting stay untouched.
  3. If the split produces more than one file, they're zipped together automatically (part-1.pdf, part-2.pdf, ...) so you get a single download either way.

Benefits

  • Free, no account or sign-up
  • Split by custom ranges or one-page-per-file
  • Multiple outputs auto-zipped into one download
  • Files never stored on the server

Examples

  • Pull out just the signature page from a long contract to send separately.
  • Break a scanned multi-chapter document into one file per chapter using custom ranges.
  • Split a batch of scanned forms into one file per form for individual filing.

FAQ

What format should ranges be in?

Comma or semicolon separated, e.g. 1-3;4-6, using 1-based page numbers.

What happens if I leave ranges blank?

Every page becomes its own separate PDF file.

Do I get one file back or several?

If splitting produces more than one file, they're zipped together automatically; a single range downloads as one PDF.

Does splitting affect quality?

No — each output page is extracted as-is, nothing is re-encoded.

Is my file stored anywhere?

No, files are processed in memory only and never written to persistent storage.
